# =========================================================
# MF Intelligence Platform — Core requirements
#
# This is everything the API needs to START and serve every
# non-ML-training endpoint (funds, watchlist, portfolio, auth,
# news, market data, predictions/inference against an
# already-trained model). It intentionally excludes the heavy
# ML/MLOps training stack (see requirements-ml.txt): those
# imports are lazy-loaded (see app/ml/models/*.py, app/ml/registry.py)
# so the app boots and every non-training endpoint works even
# when requirements-ml.txt hasn't been installed.
#
# Install for a lightweight API-only deployment (inference against
# a pre-trained model already lives in the DB) or local dev on the
# non-ML parts of the app:
#     pip install -r requirements.txt
#
# Install everything, including the ability to run model TRAINING
# (POST /ml/train, the trainer, SHAP explainability, MLflow tracking):
#     pip install -r requirements.txt -r requirements-ml.txt
# =========================================================
